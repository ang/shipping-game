# Shipping game
https://ang.github.io/shipping-game/

1. Install dependencies: `npm install`
2. Run locally: `npm run dev`. By default it will run at `http://localhost:5173`.
3. Main files are the `index.html` file and files in `src/`.
4. Deploying: `npm run deploy`. This will leverage the gh-pages package, which will run the deploy steps and push out code to the `gh-pages` branch. This is the actual branch deployed to the github page.

Ascii art from https://www.asciiart.eu/space/planets. Special shoutout to "jgs" and "JT" for their ascii art.
